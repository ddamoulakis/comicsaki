# Comicsάκι — Checklist δοκιμής με εικονικούς λογαριασμούς

Χρησιμοποίησε **2 λογαριασμούς** σε **2 διαφορετικά sessions** (π.χ. Chrome + Incognito, ή laptop + κινητό).

| | Email | Password | Session |
|---|-------|----------|---------|
| **Α — Πωλητής** | `…+seller@…` | | Browser / συσκευή 1 |
| **Β — Αγοραστής** | `…+buyer@…` | | Browser / συσκευή 2 |

---

## 0. Προετοιμασία Supabase (προαιρετικό για QA)

- [ ] Dashboard → Authentication → Email → προσωρινά OFF το **Confirm email**
- [ ] Μετά το QA, ξαναάνοιξέ το για production

---

## 1. Δημιουργία λογαριασμών

### Λογαριασμός Α
- [ ] Προφίλ → Εγγραφή (email/password ή Google)
- [ ] Confirm email (αν ζητηθεί)
- [ ] Συμπλήρωση **ονόματος εμφάνισης + πόλης**

### Λογαριασμός Β
- [ ] Άλλο session → Εγγραφή με δεύτερο email
- [ ] Συμπλήρωση ονόματος + πόλης

---

## 2. Guest (χωρίς login)

- [ ] ΑΡΧΙΚΗ φορτώνει αγγελίες / νέες κυκλοφορίες
- [ ] ΝΕΕΣ (Νέα Κυκλοφορία) — εβδομάδα, search, φίλτρα, κάρτες
- [ ] ΑΓΓ — δημόσια λίστα αγγελιών
- [ ] ΣΥΛ — demo/mock δεδομένα (όχι cloud)
- [ ] Προσθήκη UI ανοίγει (scan / barcode / manual)
- [ ] Δημιουργία αγγελίας / αγορά → προτροπή για σύνδεση

---

## 3. Λογαριασμός Α — Συλλογή & αγγελία

- [ ] Προσθήκη → Manual (ή scan) → αποθήκευση στη συλλογή
- [ ] Το item φαίνεται στη ΣΥΛ του Α
- [ ] Favorite / wishlist / read flags δουλεύουν
- [ ] ΑΓΓ → νέα αγγελία + φωτό + τιμή → δημοσίευση
- [ ] Προφίλ → Οι αγγελίες μου → εμφανίζεται
- [ ] Προφίλ → Μηνύματα → άδειο στην αρχή

---

## 4. Λογαριασμός Β — Αγορά / chat / rating

- [ ] Βλέπει την αγγελία του Α στο feed
- [ ] Αίτημα αγοράς (purchase request)
- [ ] Προσφορά (offer) με άλλο ποσό
- [ ] Μήνυμα στο chat της αγγελίας
- [ ] Report αγγελίας (χωρίς crash)
- [ ] Βαθμολογία πωλητή (αν είναι διαθέσιμη)
- [ ] Αποθήκευση δικού του κόμικ στη συλλογή Β (χωρίς να επηρεάζει τον Α)

---

## 5. Επιστροφή στον Α

- [ ] Inbox / Μηνύματα: φαίνεται αίτημα / offer / μήνυμα από Β
- [ ] Αποδοχή ή απόρριψη αιτήματος
- [ ] Απάντηση στο chat → ο Β το βλέπει

---

## 6. Απομόνωση λογαριασμών

- [ ] Logout Α → ΣΥΛ ξανά demo
- [ ] Login Β → μόνο δεδομένα Β
- [ ] Login Α → μόνο δεδομένα Α (συλλογή + αγγελίες)

---

## 7. Νέες κυκλοφορίες (ΝΕΕΣ)

- [ ] Εβδομάδα πλοηγείται (βέλη)
- [ ] Search φιλτράρει τίτλους
- [ ] Φίλτρα ανοίγουν / εφαρμόζονται
- [ ] Αγαπ. (καρδιά) αποθηκεύεται τοπικά στη συσκευή
- [ ] Συλλογή (+) προσθέτει (ή ανοίγει manual αν αποτύχει)

> Σημείωση: τα αγαπημένα νέων κυκλοφοριών είναι **ανά συσκευή**, όχι ανά λογαριασμό.

---

## 8. Cover / Barcode (προαιρετικό)

- [ ] Barcode scan ή χειροκίνητο ISBN
- [ ] Cover scan → αποτελέσματα (κινητό με κάμερα)
- [ ] Αποθήκευση στη συλλογή μόνο όταν είσαι συνδεδεμένος

---

## Γρήγορο σετ (ελάχιστο)

1. [ ] Α + Β δημιουργήθηκαν, προφίλ ολοκληρωμένο  
2. [ ] Α: 1 item συλλογής + 1 αγγελία  
3. [ ] Β: αγορά / offer / μήνυμα  
4. [ ] Α: απάντηση στο inbox  
5. [ ] Logout/login → δεδομένα δεν αναμειγνύονται
